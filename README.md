## Personal Portfolio (Dark Mode)

A minimalist, dark-mode personal portfolio site built as a single `index.html` file with embedded CSS and JavaScript. Designed for a Product Manager profile with sections for About, Work, Projects, Blog, Media, Interests, and Headshot.

## Features

- Single-file setup (HTML + CSS + JS)
- Modern dark-mode design system
- Responsive layout for mobile, tablet, and desktop
- Smooth hover and micro-interactions
- Projects with year + tags
- Media and blog links
- Headshot download button

## How to Run

Open `index.html` in your browser:

- Windows: double-click the file, or right-click → Open with → your browser
- macOS: double-click the file

## Customize Content

Edit the following sections in `index.html`:

- **Header**: name, role, social links
- **About**: 4 paragraphs of bio
- **Work**: roles, dates, descriptions
- **Projects**: titles, years, descriptions, tags
- **Blog/Media**: add or update links
- **Interests**: update items and links
- **Headshot**: set your file name in `href`

## Assets

Place these files in the same folder as `index.html`:

- `headshot.jpg` (or update the filename in the Headshot section)
- `resume.pdf` (or update the resume link)


## Design System (Dark Mode)

- Background: `#0F1115`
- Card background: `#161A22`
- Borders: `#232837`
- Primary text: `#E6EAF0`
- Secondary text: `#A4ACB9`
- Muted text: `#7A8293`
- Accent: `#4F7DFF`
- Accent hover: `#6B92FF`

## Fonts

- **Headers/Subheadings**: Montserrat
- **Body text**: Arial

## Notes

This project is intentionally lightweight with no build tools or external dependencies beyond Google Fonts.
